# 太原重工 燃油叉车全柴协议故障码测试

本项目是一个专用于**太原重工燃油叉车全柴协议**的 UDS DTC 故障码诊断交互仿真工具。它充当车辆 ECU/服务器端，监听 T-BOX 发送的 UDS 0x19 服务诊断请求并做出符合协议约定的交互响应。

同时，为了维持正常的总线通信与避免 T-BOX 报转速丢失故障，工具在启动后会自动在后台线程以 **20ms** 为周期持续发送 J1939 背景发动机转速报文：
- **发动机转速报文**: `0CF00400 FF FF 7E 10 27 FF FF FF` (代表 1250 rpm)

## ⚙️ 验证场景及交互步骤

### 场景 1：验证【无故障码】（最简单单帧交互）
- **触发条件**：收到 T-BOX 请求报文
  ```
  ID: 18DA00F1  Data: 05 19 42 33 04 1E FF FF
  ```
- **立即应答**：发送单帧响应报文
  ```
  ID: 18DAF100  Data: 06 59 42 33 04 1E 00 00
  ```
- **说明**：单帧数据长度 $\le 7$ 字节，发完该条交互即结束。

### 场景 2：验证【单故障码】（处理一次流控交互）
- **触发条件**：收到 T-BOX 请求报文 `18DA00F1`；
- **响应首帧**：立即响应首帧（First Frame）
  ```
  ID: 18DAF100  Data: 10 0B 59 42 33 04 1E 00
  ```
- **等待流控**：此时停止发送，等待总线上出现 T-BOX 回复的流控帧（Flow Control Frame）
  ```
  ID: 18DA00F1  Data: 30 00 0A FF FF FF FF FF
  ```
- **响应连续帧**：监测到上述流控帧后，立即发送响应连续帧（Consecutive Frame）
  ```
  ID: 18DAF100  Data: 21 01 12 34 56 AA FF FF
  ```
- **说明**：该交互成功触发 T-BOX 解析出 1 个故障码（如国四/国六环保协议关注的 DTC）。

### 场景 3：验证【多故障码】（处理流控 + 两条连续帧）
- **触发条件**：收到 T-BOX 请求报文 `18DA00F1`；
- **响应首帧**：立即响应首帧（First Frame）
  ```
  ID: 18DAF100  Data: 10 10 59 42 33 04 1E 00
  ```
- **等待流控**：等待总线上出现 T-BOX 回复的流控帧（Flow Control Frame）
  ```
  ID: 18DA00F1  Data: 30 00 0A FF FF FF FF FF
  ```
- **发送连续帧 1**：监测到上述流控帧后，立即发送连续帧 1
  ```
  ID: 18DAF100  Data: 21 01 12 34 56 AA 02 AB
  ```
- **延时发送连续帧 2**：延时 **10ms** 后，紧接着发送连续帧 2
  ```
  ID: 18DAF100  Data: 22 CD EF 55 FF FF FF FF
  ```
- **说明**：该交互成功触发 T-BOX 解析出 2 个或多个故障码。

## 🚀 如何运行测试

### 1. 关闭冲突服务
确保后台运行的 `can_service.py` 已经关闭，以释放物理 USB-CAN 设备占用通道。

### 2. 运行仿真工具
进入本测试文件夹并启动：
```bash
python AutoCantest/tyzg_fuel_forklift_quanchai_dtc_test/simulate_dtc.py
```
此时终端会打印出场景选择列表：
```
============================================================
  太原重工 燃油叉车全柴协议故障码测试
============================================================
 [1] 验证【无故障码】 (单帧交互)
 [2] 验证【单故障码】 (处理一次流控)
 [3] 验证【多故障码】 (处理流控 + 两条连续帧)
------------------------------------------------------------
请选择验证场景 (输入序号 1/2/3): 
```
直接输入对应序号即可开始监听与应答交互。

或者，你也可以通过可选的命令行参数直接指定要测试的场景与物理 CAN 连接属性（默认参数为：USBCAN2, 250kbps, CAN1）：
```bash
# 自动启动场景 3 并在 CAN1 通道上进行测试
python AutoCantest/tyzg_fuel_forklift_quanchai_dtc_test/simulate_dtc.py --scenario 3 --baud 250 --can-idx 0
```
